# CNC PRO — Dashboard

> **Локализация:** RU / UA  
> Веб‑панель для контроля станков, чек‑листов ОТК и отчетности.

---

## 🇷🇺 Русский

### Возможности
- мониторинг статусов станков и времени смены;
- чек‑лист ОТК с историей замеров;
- отчеты и выгрузка в Excel;
- Telegram‑уведомления и напоминания;
- база файлов/деталей и простая система ролей.

### Требования
- Node.js 18+  
- npm

### Установка и запуск
```bash
npm install
npm run dev
```

Откройте: `http://localhost:4200`

### Настройка Telegram
1. Откройте настройки приложения (иконка шестерни).
2. Введите **Bot Token** вашего бота.
3. Запустите бота и получите **Chat ID**.
4. Введите Chat ID и нажмите **Тест**.

> ⚠️ Токен хранится **локально в браузере** (localStorage). Не публикуйте его.

### Данные и хранение
Приложение использует `localStorage` для хранения станков, истории, настроек и файлов деталей.

### Скрипты
- `npm run dev` — запуск в режиме разработки (Angular CLI)
- `npm run build` — production‑сборка
- `npm run preview` — запуск production‑сборки

## 🇺🇦 Українська

### Можливості
- моніторинг статусів верстатів і часу зміни;
- чек‑лист ВТК з історією вимірів;
- звіти й експорт у Excel;
- Telegram‑сповіщення та нагадування;
- база файлів/деталей і проста система ролей.

### Вимоги
- Node.js 18+  
- npm

### Встановлення та запуск
```bash
npm install
npm run dev
```

Відкрийте: `http://localhost:4200`

### Налаштування Telegram
1. Відкрийте налаштування застосунку (іконка шестерні).
2. Введіть **Bot Token** вашого бота.
3. Запустіть бота та отримайте **Chat ID**.
4. Введіть Chat ID і натисніть **Тест**.

> ⚠️ Токен зберігається **локально у браузері** (localStorage). Не публікуйте його.

### Дані та зберігання
Застосунок використовує `localStorage` для зберігання верстатів, історії, налаштувань і файлів деталей.

### Скрипти
- `npm run dev` — запуск у режимі розробки (Angular CLI)
- `npm run build` — production‑збірка
- `npm run preview` — запуск production‑збірки
